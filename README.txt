ITCMD Brasil 2026 — site independente

Abra index.html em um navegador moderno. O site usa dados-itcmd.js para funcionar mesmo quando aberto diretamente do computador. dados-itcmd.json contém os mesmos dados em formato estruturado para integrações futuras.

Para atualizar os dados sem refazer o site:
1. Atualize os registros em dados-itcmd.json e dados-itcmd.js; ou gere ambos novamente a partir da planilha.
2. Não é necessário alterar index.html, styles.css ou app.js enquanto os nomes dos campos forem preservados.

O mapa geográfico carrega uma camada GeoJSON pública via internet. Sem internet, filtros, comparações, faixas e fontes continuam funcionando; apenas o mapa fica indisponível.
